# {{project_name}}

A starter layout for a future YAZA mobile project.

## Project layout

- `src/main.yz` contains a YAZA command-line sample.
- `mobile/android/` is reserved for Android platform integration.
- `mobile/ios/` is reserved for iOS platform integration.
- `yaza.toml` stores project metadata.

## Run the YAZA sample

```sh
yaza run src/main.yz
```

The generator does not yet create installable Android or iOS applications. Native mobile backends and device API bindings are not implemented.
