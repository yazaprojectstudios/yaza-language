## 1. Cloud-Native Microservice Comparison (6 Runtimes)

Endpoints tested under identical JSON schemas and verified HMAC-SHA256 output (`9c5ac72406f0ddfb...`, `2,000` reqs × `3` rounds, `0` failed requests):
1. `GET /healthz`: atomic counter increment
2. `GET /api/v1/quote?sku=YZ-42&qty=5&tier=gold`: discount/tax calculation + HMAC-SHA256 signature
3. `POST /api/v1/orders`: JSON request body parse + atomic order sequence + HMAC-SHA256 receipt
4. `GET /api/v1/catalog?id=500`: 10,000-row persistent embedded database primary-key lookup (`YazaBase` CLOCK LRU + Plan Cache + `arena_scope` in YAZA vs `SQLite 3` in peer runtimes)
